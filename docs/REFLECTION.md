# Reflection

This assignment helped me improve my understanding of PL/SQL GOTO statements and functions. I learned how GOTO statements can be used to move the execution of a PL/SQL program to a specific labeled section. I also learned how to create stored functions that accept parameters, perform calculations, and return a value.

Through the different tasks, I practiced using functions for calculations such as annual salary, years of service, tax, and department information. I also learned how exception handling can be used to handle errors and make PL/SQL programs more reliable.

One important thing I learned is that although GOTO can be useful in some situations, a program can sometimes be written more clearly without using it. I also learned how functions can be called directly in SQL statements.

Finally, this assignment helped me practice organizing SQL files, tests, screenshots, and documentation in a GitHub repository. Overall, the assignment improved my practical PL/SQL skills and helped me understand how these concepts can be applied when developing database programs.
